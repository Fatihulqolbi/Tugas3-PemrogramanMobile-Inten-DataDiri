# Tugas 3 - Pemrograman Mobile - Intent & Data Diri

Aplikasi Android sederhana untuk mempelajari konsep Intent (Explicit & Implicit) dan Activity Lifecycle.

## Fitur
*   **Explicit Intent**: Mengirim data Nama dan NRP antar Activity.
*   **Implicit Intent**: Mengambil foto KTM dari galeri perangkat.
*   **Activity Lifecycle**: Implementasi tombol tutup dengan `finish()` dan pemantauan `onDestroy()`.
*   **UI/UX Modern**: Desain bertema gelap (Dark Mode) dengan komponen Material 3.
